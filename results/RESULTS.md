# Results

## Release Status

This source release provides the LC-CLAP framework, default configuration, and five-seed evaluation protocol. It does not include trained checkpoints or a licensed evaluation corpus; no quantitative claim is made for this release.

## Reporting Protocol

Published results are reported as the mean and population standard deviation from five independently seeded runs. Each release record identifies the dataset at an approved public level and names the evaluated task and metric.

| Evaluation item | Current release |
| --- | --- |
| Trained checkpoint | Not distributed |
| Evaluation corpus | Not distributed |
| Aggregate metric | Not reported |
| Five-seed protocol | Available through `run_five_seed_protocol.py` |

Future releases may add approved aggregate metrics to this document when the associated data, model artifact, and evaluation scope are cleared for publication.
